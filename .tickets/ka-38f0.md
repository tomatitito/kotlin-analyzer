# Fix stale diagnostic clearing in Rust server

The server caches diagnostics and republishes them across didClose/didOpen cycles, but background project-wide analysis only publishes non-empty results. If a file becomes clean, stale diagnostics can remain visible indefinitely.

## Acceptance Criteria

- When a file previously had diagnostics and later analyzes clean, the server publishes an empty diagnostics list for that URI.
- Cached diagnostics for clean files are removed or updated to empty.
- didClose/didOpen behavior no longer resurrects stale diagnostics for clean files.
