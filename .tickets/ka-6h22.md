# Auto-insert Kotlin package declaration for new src files

When a user creates a new Kotlin source file somewhere under a `src` source root, the analyzer/editor integration should automatically insert the appropriate `package ...` declaration at the top of the file based on the file path relative to the source root.

Example: creating `src/main/kotlin/com/example/Foo.kt` should populate the file with:

```kotlin
package com.example

```

This should only happen when the package can be inferred from a recognized source root and should avoid overwriting existing file contents.

## Acceptance Criteria

- New Kotlin files created under recognized `src` source roots get the correct `package` declaration inserted automatically.
- Files in the source root package get no invalid/empty package declaration.
- Existing non-empty files are not overwritten or duplicated with another package declaration.
- Behavior is covered by tests or a documented manual verification flow.
