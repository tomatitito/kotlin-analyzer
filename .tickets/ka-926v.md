# Fix sidecar Gradle deprecations before Gradle 9/10

Track sidecar build deprecations reported by ./gradlew clean assembleRuntimePayloads --warning-mode all. Current findings: 1) sidecar/build.gradle.kts:206 uses project.version inside doLast, triggering 'Invocation of Task.project at execution time' deprecation. 2) a plugin or built-in task path is still using deprecated CopyProcessingSpec.setFileMode(Integer); identify the source and eliminate it if possible before Gradle 9.

## Investigation Results

### Deprecation 1: `project.version` at execution time (breaks in Gradle 10.0)

**File:** `sidecar/build.gradle.kts`, line 206
**Context:** Inside a `doLast` block (lines 170-220) of dynamically registered `assembleRuntimePayload*` tasks:
```kotlin
val manifest = mapOf(
    "kotlinVersion" to runtimeKotlinVersion,
    "mainClass" to "dev.kouros.sidecar.launcher.LauncherMain",
    "analyzerVersion" to project.version.toString(),  // ← LINE 206
    "targetPlatform" to "any",
    ...
)
```

**Root cause:** Gradle 8.12 deprecates `Task.project` access inside `doLast`/`doFirst` because it is incompatible with the configuration cache.

**Also affected:** `grammars/pebble/sidecar/build.gradle.kts` has the same pattern at the same line number.

**Fix:** Capture `project.version` at configuration time before the `doLast` block:
```kotlin
val analyzerVersion = project.version.toString()
// ... later inside doLast:
val manifest = mapOf(
    "analyzerVersion" to analyzerVersion,
    ...
)
```

### Deprecation 2: `CopyProcessingSpec.setFileMode(Integer)` (breaks in Gradle 9.0)

**Source:** NOT in sidecar/build.gradle.kts directly. No `setFileMode` or `fileMode` calls found in any project build files.

**Likely origin:** The Shadow plugin (`com.github.johnrengelman.shadow:8.1.1`, applied at line 8 of `sidecar/build.gradle.kts`). The Shadow plugin uses `setFileMode` internally when creating shadow JARs.

**Fix options:**
1. **Upgrade Shadow plugin** to a version that uses the replacement API `filePermissions(Action)`. Check for Shadow releases ≥8.2 or equivalent that address this deprecation.
2. If no fixed version exists, document the deprecation as a known upstream issue and track the Shadow plugin's Gradle 9 compatibility.

### Current Gradle Version

`sidecar/gradle/wrapper/gradle-wrapper.properties`: Gradle **8.12**

### Copy operations in build file (lines 179-201)

Standard `copy { from(...) into(...) }` calls — these do NOT use `setFileMode` and are fine.

In `sidecar/build.gradle.kts`, capture version before the task registration/doLast closure:

Then reference `analyzerVersion` inside `doLast` instead of `project.version.toString()`.

Apply same fix to `grammars/pebble/sidecar/build.gradle.kts` if it has the same pattern.
